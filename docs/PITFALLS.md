# Грабли, на которые уже наступили

Каждый пункт - реальная поломка, найденная на живых звонках, и что с ней сделано.

## Распознавание

| Симптом | Причина | Что сделано |
|---|---|---|
| "Субтитры сделал ...", "Thank you for watching", "Продолжение следует" на тишине | Whisper обучен на видео с субтитрами | `asr.HALLUCINATION_RE`, VAD перед распознаванием |
| Одиночное "Thank you." в окне | то же, на шуме или чужом языке | отбрасывается в `transcribe_window` |
| Одна фраза 20 раз подряд с шагом в секунду ("Принцердево. Принцердево. ...") | петля декодера на коротком окне, метки времени уезжают за конец окна | `collapse_repeats`, `clean_segments` (не больше 2 одинаковых подряд), строки с началом за концом окна отбрасываются |
| Японские титры, иврит, "I'm going to go to the next video" на микрофоне | эхо звонка из динамиков | `drop_crosstalk` в live, на микрофоне только `ru/en` |
| Одна галлюцинация портит весь остаток | `condition_on_previous_text=True` | всегда False |
| Узбекская речь распознана как польская/турецкая белиберда | Whisper не знает узбекского | в течение 90 с после узбекской реплики строки на "чужих" языках отбрасываются |
| Английская фраза после узбекской записана узбекскими словами ("VPN userlaring") | принудительный узбекский режим отдавал английский второй модели | явный английский (`p(en) >= 0.6`) второй модели не отдаётся никогда |
| Первая узбекская фраза разговора распознана как русская | короткое окно, заимствования | известное ограничение; со второй фразы включается "липкий" режим |
| Каждое окно грузит 1.5 ГБ весов | mlx-whisper кэширует одну модель, live чередует две | вторая модель держится отдельно, подменяется в кэш на время вызова (`asr.use_model`) |
| Слова удваиваются, "да" x150 | склейка частичных гипотез без меток слов (LocalAgreement) | черновик + финал: черновик заменяется целиком, финал не редактируется |
| Буфер растёт до 135 с, проход по минуте | у беглого собеседника нет паузы 0.6 с | порог паузы падает с длиной буфера, жёсткий предел 8 с |
| "Are you naked?", "Gracias" посреди узбекской речи | Whisper "слышит" знакомый язык в незнакомом | иностранная строка с p(lang) ниже 0.5 - `unsure`, не переводится; междометия - `filler` |
| Строка из терминов словаря на шуме | Whisper читает промпт обратно | `glossary_readback` |
| Metal OOM при загрузке LLM после распознавания | веса Whisper занимают общую память | `uzbek.release()` и сброс кэша mlx-whisper перед большой LLM |

## Перевод

| Симптом | Причина | Что сделано |
|---|---|---|
| Своп, 21 ГБ у 12B-модели | контекст Ollama по умолчанию 32k | `num_ctx=4096` для живого перевода, отдельная модель, выгрузка после встречи |
| Перевод с микрофона опоздал на 14 с | "угу" ("Mm-hmm") забивали очередь перевода | междометия не переводятся |
| Перевод отстаёт на 10-30 с | модель с рассуждениями через OpenAI-совместимый `/v1` у Ollama | `kind="ollama"`, `/api/chat` с `think: false` |
| Первые переводы опаздывают на ~30 с | холодная загрузка модели | прогрев одним вызовом при старте |
| Узбекский текст вернулся без перевода | промпт "если уже на этом языке - верни как есть" сбивал модель | для иностранной речи этой фразы нет, вместо неё "исходный текст не повторяй" |
| Обрывки фраз переводятся бессмысленно | реплика без контекста | 4 предыдущие реплики в промпте |
| LLM-корректура вписала имя спикера в текст ("Имя: Имя: ...") | корректор видел узбекские строки | строки второго языка не отдавать в корректуру и слияние движков |

## Голоса

| Симптом | Причина | Что сделано |
|---|---|---|
| Разные люди похожи на 0.69 | в отпечаток пользователя попали реплики, где говорил и звонок: микрофон слышал собеседника | в отпечаток только реплики, где остальные дорожки тихие (`OTHER_QUIET_DB`) |
| Дорожка реплики определялась неверно на одновременной речи | сравнивалась громкость каждой реплики отдельно | дорожка определяется для метки целиком голосованием, уровень речи дорожки - 75-й перцентиль |
| Эмбеддинг падает с "num_frames: 0" | реплика за концом более короткой дорожки | реплика обрезается по длине дорожки, короче 1 с пропускается |
| Модель эмбеддингов падает на длинном куске | минутный вход | берётся середина, 10 с |
| Голос пользователя похож на "звонок" в некоторых встречах | в тех записях системная дорожка содержала голос самого пользователя (второе устройство в звонке) | имя отдаётся одной метке, самой похожей; пользователь видит сходство и правит |

## Тихие свои реплики vs голоса в комнате

Автоматически пометить "голос из комнаты" для реплик на основном языке не получилось: когда
пользователь отклоняется от микрофона, его слова на 30 дБ тише и по отпечатку "не похожи"
(сходство 0.03-0.18, как у чужих). Поэтому для основного языка это только подсказка на
проверку, не автоматическое удаление. Для второго языка, на котором пользователь не говорит,
правило простое: такой язык на микрофоне - это комната.
