# CLAUDE.md

Модуль для встраивания в чужую систему записи/проведения встреч: живые субтитры с переводом
(узбекский через отдельную модель), окно-оверлей, библиотека голосов.

- Задача "подключить модуль" -> следуй docs/AGENT.md по шагам, начиная с шага 0.
- Пороги и их происхождение -> docs/CALIBRATION.md; известные поломки -> docs/PITFALLS.md.
- Тесты: `pytest -q` (без моделей и сети), линтер: `ruff check src tests examples`.
- Все вызовы моделей - через `asr.LOCK`. Вторую модель не вызывать через mlx_whisper напрямую,
  только `asr.use_model` (иначе перезагрузка весов на каждом окне).
